# Zen Novel sources

Signed source definitions for the Zen Novel iOS app. To use them, paste this link in the app under **Sources › Add source**:

```
https://raw.githubusercontent.com/harveyj123/zen-novel-sources/main/index.json
```

Every file is signed with the publisher key (fingerprint `140469af…49cca8`); the app verifies each one and refuses anything edited by hand. Updates are published by replacing the whole directory with a newly signed build.
